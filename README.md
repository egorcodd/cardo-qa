# Cardo

Учебный банковский стенд для практики QA.

## Локальный запуск

Нужен Docker с поддержкой Compose.

```sh
docker compose up -d --build
```

- Приложение: http://localhost:8942
- API и Swagger: http://localhost:8942/api/docs
- PostgreSQL: localhost:5434, база `cardo`, пользователь `cardo_qa`, пароль `cardo_qa_dev`.

Зарегистрируйся по номеру телефона и паролю. Подтверждение по SMS не требуется. Новый аккаунт получает нулевые денежные балансы и пустую историю. Используй «Пополнить», затем найди другого клиента Cardo по телефону или номеру рублёвой карты. Перед отправкой появится имя получателя. Перевод списывается у отправителя и зачисляется получателю; обе операции сохраняются в истории. Переводы доступны в рублях. Выбора стороннего банка в интерфейсе нет.

При регистрации автоматически создаются три уникальные карты. Отдельного выпуска карт нет.

## Готовые аккаунты

| Аккаунт                     | Телефон          | Пароль         |
| --------------------------- | ---------------- | -------------- |
| Cardo Плюс, Алексей Смирнов | +7 999 000-10-01 | CardoDemo2026! |
| Обычный, Мария Волкова      | +7 999 000-10-02 | CardoDemo2026! |

Эти аккаунты создаются один раз при запуске Gateway: карты, большие балансы, готовая история и сообщения. Повторный запуск не восстанавливает потраченные деньги и не сбрасывает изменения. Для независимых проверок зарегистрируй собственные аккаунты. Два аккаунта одновременно открывай в разных профилях браузера или на разных устройствах.

Для PWA на телефоне нужен HTTPS-адрес стенда. На iPhone добавь Cardo на домашний экран, на Android установи через меню браузера. В настройках можно разрешить push и выбрать категории сообщений. Предложения приходят автоматически при включённой категории. Уведомление о переводе открывает собственную запись операции.

`docker compose down` останавливает стенд и сохраняет данные в томе `cardo-data`. Удаление этого тома удалит данные.

## Проверка и разработка

Node.js 24 или новее.

```sh
npm ci
npm run typecheck
npm test
npm run build
```

При запущенном PostgreSQL доступны `npm run dev` и `npm run test:integration`. Для отдельных адресов базы используются переменные `DATABASE_URL` и `TEST_DATABASE_URL`. Расширенные проверки Banking и Engagement запускаются с `CARDO_BANKING_INTEGRATION=1` и `CARDO_ENGAGEMENT_INTEGRATION=1`; при необходимости укажи `TEST_BANKING_DATABASE_URL` и `TEST_ENGAGEMENT_DATABASE_URL`. Они создают и удаляют только свои временные данные.

Настройки портов находятся в `.env.example`.

## Курсы валют

Сервис Rates получает официальные ежедневные курсы USD и EUR из XML Банка России по HTTPS: https://www.cbr.ru/scripts/XML_daily.asp. Это курс ЦБ на указанную дату, он не меняется каждую секунду. Сервис проверяет обновления при запуске и затем раз в час. Курс за одну единицу валюты учитывает номинал из источника и сохраняется в PostgreSQL отдельной версией.

GET /api/rates возвращает `asOf` — дату действия курса, `source: "cbr"`, `sourceUrl`, `fetchedAt` — время последней успешной проверки и `stale`. При недоступности ЦБ используется последний сохранённый официальный курс с `stale: true`. Если официальный курс ещё не был получен, API отвечает 503; учебные значения из старого `fixture-v1` не подставляются. Обновление курсов не меняет сохранённые результаты обмена и их повторные запросы.

## Переводы и уведомления

В интерфейсе получатель Cardo находится по телефону или номеру карты. Комиссия за перевод — 500 ₽ на Стандарте и 100 ₽ на активном Cardo Плюс. Получатель получает указанную сумму, комиссия списывается дополнительно и отражается отдельной операцией. Итог показывается до отправки. Пополнение и обмен валют без комиссии; повтор того же запроса возвращает сохранённую квитанцию без повторного списания.

На телефоне сумма перевода вводится встроенной клавиатурой Cardo. Телефон и номер карты используют системную клавиатуру. На компьютере сумму можно вводить обычной клавиатурой.

Категория «Предложения» в настройках включает обычные банковские сообщения про карты, переводы, обмен валют и Cardo Плюс. В пуле 180 текстов, без учебных советов и шуток про QA. Первое предложение приходит через четыре часа, следующие каждые четыре часа. Для каждого аккаунта порядок свой; сообщение повторяется через 180 отправок. График сохраняется после перезапуска. Выключение останавливает новые предложения и ожидающие push; история сохраняется. Сообщения о поступлении денег, выполненном переводе и пополнении приходят по факту операции. Для системных уведомлений нужна разрешённая push-подписка и поддержка устройства и браузера. Создания напоминаний в интерфейсе нет.
