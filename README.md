# Cardo

Учебный банковский стенд для практики QA. В приложении есть регистрация, карты, переводы, пополнение, история операций, обмен валют и уведомления. Работать со стендом можно через веб-интерфейс, API и базу данных.

Проект состоит из веб-приложения и нескольких сервисов. Фронтенд использует React и Vite, серверная часть — Node.js и TypeScript, данные хранятся в PostgreSQL.

## Запуск через Docker

Нужен Docker с поддержкой Compose. Выполни из корня репозитория:

```sh
docker compose up -d --build
```

| Компонент | Адрес |
| --- | --- |
| Приложение | http://localhost:8942 |
| Swagger API | http://localhost:8942/api/docs |
| PostgreSQL | localhost:5434, база `cardo` |

Параметры Compose находятся в `.env.example`. Чтобы изменить порты или настройки окружения, создай рядом файл `.env` с нужными значениями.

Остановить стенд можно командой `docker compose down`. Данные сохраняются в томе `cardo-data` между запусками.

## Структура проекта

| Каталог | Назначение |
| --- | --- |
| `apps/web` | Интерфейс приложения и PWA |
| `services/gateway` | Входная точка API и раздача веб-приложения |
| `services/customer` | Аккаунты, авторизация, профиль и настройки |
| `services/banking` | Карты, счета, переводы и история операций |
| `services/engagement` | Уведомления, push и награды |
| `services/rates` | Получение и хранение курсов валют |
| `packages` | Общие контракты и серверные инструменты |
| `infra` | Подготовка PostgreSQL |
| `scripts` | Запуск, сборка и проверки |
| `tests` | Автоматические тесты |

У сервисов отдельные схемы и роли в PostgreSQL. Веб-приложение обращается к ним через Gateway.

## Работа с исходниками

Нужен Node.js 24 или новее. Для запуска сервисов вне Docker сначала останови полный Compose-стенд, затем подними только базу и подготовь приложение:

```sh
docker compose down
docker compose up -d postgres db-setup
npm ci
npm run build
npm run dev
```

`npm run dev` запускает Gateway и четыре сервиса. Приложение доступно на http://localhost:8942. После изменения фронтенда повтори `npm run build`.

| Команда | Назначение |
| --- | --- |
| `npm run typecheck` | Проверка типов и исходников интерфейса |
| `npm test` | Автоматические тесты |
| `npm run test:integration` | Интеграционные проверки |
| `npm run build` | Сборка веб-приложения и PWA |

Интеграционные проверки запускаются при работающих сервисах и PostgreSQL.

## PWA

Cardo можно добавить на домашний экран iPhone или установить на Android через браузер. Для использования на телефоне нужен HTTPS-адрес стенда. Push-уведомления требуют поддержки браузера и разрешения пользователя.
