# Cardo

Учебный банковский стенд для практики тестировщиков. Здесь можно зарегистрироваться, посмотреть свои карты, пополнить счёт, перевести деньги другому пользователю, открыть историю операций и обменять валюту.

Стенд можно использовать на занятиях с учениками и для самостоятельной практики. Один сценарий можно проверять в интерфейсе, через API и по записям в базе данных.

## Что можно практиковать

- Ручное тестирование: проходить пользовательские сценарии, проверять формы и валидацию, составлять чек-листы и тест-кейсы.
- Проверку интерфейса: смотреть отображение на разных размерах экрана, состояния кнопок, сообщения и поведение при обновлении страницы.
- Работу с API: отправлять запросы через Swagger или Postman, разбирать ответы и сравнивать их с данными в интерфейсе.
- Работу с базой данных: выполнять SQL-запросы и проверять, что сохранилось после действий пользователя.
- Работу с DevTools: изучать запросы, ответы и сообщения в консоли.

Для практики удобно создать несколько аккаунтов и открыть их в разных профилях браузера. Так можно проследить перевод со стороны отправителя и получателя. Найденные проблемы можно оформлять в баг-репорты и обсуждать на занятиях.

## Локальный запуск

Стенд можно развернуть на своём компьютере через Docker Compose. Установи Docker с поддержкой Compose и запусти его. Затем скачай репозиторий, открой терминал в его папке и выполни:

```sh
docker compose up -d --build
```

Первый запуск занимает время: Docker скачивает зависимости и собирает приложение. После запуска доступны:

| Что открыть | Адрес |
| --- | --- |
| Приложение | http://localhost:8942 |
| Swagger с описанием API | http://localhost:8942/api/docs |
| База данных | localhost:5434, база `cardo` |

Настройки запуска перечислены в `.env.example`. Если нужно изменить порты, создай рядом файл `.env` с нужными значениями.

## Остановка

```sh
docker compose down
```

Аккаунты и операции сохраняются между запусками. Чтобы продолжить практику, снова выполни команду запуска.
